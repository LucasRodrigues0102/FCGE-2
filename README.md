# FCGE-2
Projeto para o segundo semestre do curso de TADS: um sistema de fluxo de caixa e gerenciamento de estoque, originalmente desenvolvido em C, que foi refeito em C#, com o uso de Windows Forms para criar uma interface gráfica.

Esse projeto foi no segundo semestre de 2024, com o objetivo de aprimorar o trabalho realizado no primeiro semestre em C, adicionando uma interface e integração com banco de dados. O projeto foi desenvolvido em grupo, composto por três integrantes: fiquei responsável por todo o desenvolvimento em C#, enquanto um colega cuidou da integração com o banco de dados e o outro ficou responsável pela documentação.

A versão publicada nesse repositório não possui a integração com MySQL presente na versão final do projeto. Dessa forma, os dados são perdidos ao se fechar o programa.

Esse repositório tem como objetivo apresentar minhas habilidades em C# e no desenvolvimento de interfaces gráficas por meio de um projeto acadêmico. Por isso, ele está sendo disponibilizado mais de um ano após seu desenvolvimento e contém apenas os componentes que foram implementados por mim.
